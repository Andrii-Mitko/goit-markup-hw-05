## About the Project

WebStudio is a business landing page presenting a digital agency's services, team, and portfolio.

The project focuses on building structured web pages with HTML5 and CSS3, creating interactive UI elements, and implementing modal window functionality using vanilla JavaScript.

## Features

- Semantic HTML5 structure
- Flexbox-based layouts
- SVG icons using an external SVG sprite
- Hero section with a background image and gradient overlay
- Team section with social media icons
- Portfolio gallery with animated overlay effects
- Hover and focus interactions
- CSS transitions and transforms
- Interactive modal window
- Contact form with custom input styling and checkbox
- Newsletter subscription form UI

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Flexbox
- SVG
- Google Fonts
- Modern Normalize
